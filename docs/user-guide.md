# Shineos Local AI — ユーザーマニュアル

> 無料で使える、パソコンの中だけで動く AI チャットツールです。
> インストールした後は、インターネットに接続しなくても使えます。

## 1. 必要なもの

| 項目 | 条件 |
|------|------|
| OS | Windows 10 / 11（64bit） |
| メモリ | 8GB 以上（16GB 以上推奨） |
| 空き容量 | 15GB 以上 |
| インストール時 | インターネット接続が必要（Ollama本体1.5GB＋AIモデル3.4GBなど**合計約6GB**をダウンロードします。所要時間は回線によりますが、およそ30〜90分です） |

## 2. インストール方法

1. [GitHub Releases](https://github.com/Shineos/shineos-local-ai/releases) ページから `ShineosLocalAI-Setup-<version>.exe` をダウンロード
2. ファイルをダブルクリック（コード署名済みのため、通常は警告なく実行できます。まれに発行元の確認が出る場合は「実行」をクリック）
3. 管理者権限の確認が出たら「はい」をクリック
4. AIモデルを選択:
   - **qwen3.5:4b（推奨）** — 性能重視。16GBメモリのパソコンで快適
   - **qwen3.5:2b（軽量）** — 8GBメモリのパソコンでも軽快
5. インストールが完了するまで待つ（進捗画面が表示されます）
6. 完了後、ブラウザで **http://localhost:8080** を開く

**これで完了です。アカウント登録もログインも不要で、そのままチャットを始められます。**

デスクトップに「Shineos Local AI」のショートカット（ブラウザで開く）と「ShineosLocalAI-はじめに.txt」が作成されます。

## 3. 使い方

### チャット
- 画面下部の入力欄に日本語で質問を入力し、送信
- 使用モデルは画面右上のメニューから切り替えられます（qwen3.5:4b）

### 文書の質問（RAG）
1. チャット画面の左下「+」をクリック
2. PDF などの文書ファイルをアップロード
3. 「この文書の◯◯について教えて」と質問すると、**文書の該当箇所を引用した回答**が返ります

※ 文書はすべてパソコンの中だけで処理され、外部に送信されません。

### Web検索（オプション）
- チャット入力欄の **Web検索ボタン** をONにすると、最新のインターネット情報を参照して回答します（DuckDuckGo・APIキー不要）
- 注意: 検索サービスの利用制限により、一時的に検索結果が空になることがあります。しばらく待ってから再度お試しください
- **完全オフラインで使いたい場合**: Web検索ボタンをOFFのままにしてください。これだけで、一切インターネットに接続しません

### PCの再起動後
自動的にサービスが起動するので、ブラウザで http://localhost:8080 を開くだけです。

## 4. アンインストール

1. 設定アプリ → アプリ → インストールされているアプリ → 「Shineos Local AI」→ アンインストール
2. サービス・ファイルが自動的に削除されます

※ AIモデル（Ollama）は別途インストールされるため、アンインストール後も残ります。モデルごと削除したい場合は `ollama` コマンドで削除するか、Ollama 本体をアンインストールしてください。

## 5. 困ったときは

| 症状 | 対処 |
|------|------|
| ブラウザで開けない | 数分待ってから再読み込み。それでもダメなら PC を再起動して http://localhost:8080 を開く |
| ログイン画面が表示された | ブラウザの履歴・Cookieを削除して再読み込み（まれに表示されることがあります） |
| 回答が遅い | 8GBメモリのパソコンでは仕様です。ブラウザの不要なタブを閉じると改善します。軽量モデル（qwen3.5:2b）に切り替えるには、インストーラを再実行して「軽量」を選択してください |
| エラーが発生した | `C:\Program Files\ShineosLocalAI\logs` のログを確認。またはインストーラを再実行（途中から再開されます） |
| サービスの状態を確認したい | 管理者PowerShellで `sc query ShineosLocalAI` |

### よくある質問（FAQ）

**Q. インストールに時間がかかるのはなぜ？**
Ollama本体（1.5GB）とAIモデル（3.4GB）など、**合計約6GB**をダウンロードするためです。回線速度によりますが30〜90分かかります。完了まではウィンドウを閉じないでください。

**Q. インターネットなしでも使えますか？**
はい。インストール完了後は、Web検索ボタンをOFFにしていれば完全にオフラインで動作します。機密資料の質問にも安心して使えます。

**Q. アップロードした文書はどこに保存されますか？**
パソコンの中（`C:\Program Files\ShineosLocalAI\data`）だけです。外部に送信されることはありません。※ 再インストールすると初期化されます。

**Q. 会社で使ってもいいですか？**
モデル・ソフトウェアは商用利用可能なライセンス（Apache 2.0 等）です。本ツールは無料です。導入支援やカスタマイズのご相談は https://shineos.com/contact/ まで。

**Q. バージョンアップはありますか？**
GitHub Releases ページで新しいバージョンを公開した際は、インストーラを再実行してください（データは初期化されます）。
